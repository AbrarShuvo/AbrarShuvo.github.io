The problem

New business was arriving faster than anyone could file it.

Enquiries land in an inbox all week. Someone opens each one, copies the name and the request into a spreadsheet, and marks it later if it goes anywhere. The copying is dull, it happens in bursts, and when the week gets busy a lead quietly goes unanswered.

Before

After
The tracker fills itself

How it works

Decisions I made

Fit the team's habits, don't fight them

An automation nobody trusts gets switched off in a week. So the rule was simple: it adds work to the sheet, it never takes work away from the person using it.

Excel, not a new app

The team already lives in a spreadsheet. Giving them a new tool to learn would have been the fastest way to be ignored.

Human edits always win

If someone has typed a note or changed a status by hand, the pipeline leaves it alone and only adds what is new.

Nothing deleted, ever

A suspected duplicate is marked, not removed, so a wrong guess costs a glance rather than a lost lead.

The result

The week's leads, filed and visible, without anyone typing them in.
